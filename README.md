# PC Turbo Ultimate - Releases

Canal officiel des mises à jour de PC Turbo Ultimate.

Les fichiers latest.yml, PC-Turbo-Ultimate-Setup-*.exe et *.blockmap sont publiés automatiquement par electron-builder. Ne pas modifier ces fichiers manuellement.

## Installation

Téléchargez le dernier installateur PC-Turbo-Ultimate-Setup-*.exe. L'installation se fait dans le profil utilisateur, sans administrateur, et les mises à jour suivantes sont automatiques.

La version portable ne peut pas se mettre à jour automatiquement.
